# Buy Now button — AZ-104 course page

Static HTML mockup. No build step, no dependencies (Poppins loads from Google Fonts).

## Run
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Publish on GitHub Pages
Settings → Pages → Source: Deploy from branch → `main` / root. Live at:

    https://smanibharathi1920-coder.github.io/buy-now/

## Files
- `index.html` — the course page with the orange Buy Now button in the hero
- `screenshots/buynow/` — exported PNG screenshots
